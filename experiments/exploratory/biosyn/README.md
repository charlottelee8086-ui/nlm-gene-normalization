# BioSyn experiments

This directory documents exploratory BioSyn-based linking experiments.

Selected historical scripts are preserved under `legacy/root/`:

- `dense_link_biosyn_gene.py`
- `eval_biosyn_gene.py`
- `dense_link_biosyn_gnormplus_filtered.py`
- `eval_biosyn_gnormplus_filtered.py`

These experiments explored neural biomedical entity linking as an alternative to the main dictionary and SapBERT candidate pipelines.
