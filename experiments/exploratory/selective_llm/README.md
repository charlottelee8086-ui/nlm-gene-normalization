# Selective LLM experiments

This directory documents exploratory analyses of when LLM-based normalization helps or hurts.

Selected historical scripts are preserved under `legacy/root/`:

- `analyze_llm_hurts.py`
- `simulate_selective_llm_gain.py`
- `compare_llm_vs_pubmedbert_trigger49.py`
- `eval_llm_trigger49_predictions.py`

The goal was to investigate whether an LLM should be applied selectively to difficult cases rather than uniformly to every mention.
