# PubMedBERT experiments

This directory documents the exploratory PubMedBERT branch.

Selected historical scripts are preserved under `legacy/root/`:

- `clean_pubmedbert_ner.py`
- `predict_pubmedbert_ner.py`
- `link_pubmedbert_predictions.py`
- `eval_pubmedbert_linked.py`

The branch explored PubMedBERT-based gene recognition followed by GeneID linking.

It was not selected as one of the main report pipelines.
