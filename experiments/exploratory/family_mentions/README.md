# Family-mention analysis

This directory documents exploratory work on gene-family and ambiguous mentions.

Selected historical scripts are preserved under `legacy/root/`:

- `analyze_family_candidate_coverage.py`
- `analyze_family_gold_structure.py`
- `build_family_member_llm_prompts.py`
- `eval_family_member_llm_predictions.py`
- `export_family_hard_cases.py`

Additional family reranking, prompt-generation, and evaluation variants are also preserved in `legacy/root/`.

These experiments were useful for studying difficult normalization cases but were not part of the main full-test comparison.
