# Hybrid normalization experiments

This directory documents exploratory pipelines combining several normalization components.

Selected historical scripts are preserved under `legacy/root/`:

- `build_hybrid_tmp_SA_cleaned.py`
- `eval_hybrid_cleaned.py`
- `eval_hybrid_pubmedbert_gnormplus.py`

These experiments tested combinations of rule-based and neural normalization components.

They are preserved as exploratory work rather than part of the main report comparison.
