# Synonym-rescue experiments

This directory documents exploratory attempts to recover mentions missed by the main candidate-generation pipeline.

Selected historical scripts are preserved under `legacy/root/`:

- `build_rescue_dictionary.py`
- `analyze_single_gene_missing_rescue.py`
- `eval_gold_normalization_with_rescue.py`
- `eval_rescue_belb_style.py`

The main idea was to use additional symbol and synonym information to improve coverage.
